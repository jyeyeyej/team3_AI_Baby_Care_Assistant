<aside>

**Streamlit 기반 테스트용 AI 육아 도우미 화면 구성**

## 1. 화면 원칙

- 실제 회원가입 대신 준비된 가짜 사용자를 선택합니다.
- 선택된 `user_id`와 `baby_id`를 세션에 저장합니다.
- 홈과 AI 육아 도우미는 같은 수유 알림 상태를 표시합니다.
- 저장·수정·삭제 직전에는 반드시 최종 확인 화면을 보여줍니다.
- 의료 답변에는 출처·확인일·주의 문구를 표시합니다.
- 모바일에 가까운 한 열 레이아웃으로 구성합니다.

## 2. 최종 메뉴

1. 홈
2. AI 육아 도우미
3. 육아 관리
4. 내 정보

로그인 전에는 시작·테스트 로그인 화면만 표시합니다.

## 3. 테스트 로그인

> 테스트할 사용자를 선택해 주세요.
> 
- 사용자 카드 선택
- FastAPI `POST /api/test-login` 호출
- 반환된 사용자·아기 정보를 `st.session_state`에 저장
- 아기가 없으면 아기 등록 화면, 있으면 홈으로 이동

비밀번호·회원가입·JWT는 구현하지 않습니다.

## 4. 홈

### 표시 카드

- 수유 알림
- 마지막 수유·최근 수면·최근 배변
- 키·몸무게 성장 그래프
- 다음 예방접종
- 월령별 가이드

### 수유 알림 카드

> 🍼 마지막 수유 후 설정한 시간이 지났어요. 아기의 배고픔 신호를 확인해 주세요.
> 

`[수유했어요]` `[10분 후]` `[건너뛰기]`

- **수유했어요**: AI 육아 도우미에서 방식·양·시각 입력 → 확인 → 저장
- **10분 후**: 카드를 숨기고 현재 시각부터 10분 뒤 다시 표시
- **건너뛰기**: 기록 없이 현재 시각부터 설정 간격 뒤 다시 표시

> 이번 알림을 건너뛰었어요. 3시간 후 다시 알려드릴게요.
> 

## 5. AI 육아 도우미

### 구성

- 현재 아기 선택·기본정보 요약
- 홈과 동일한 알림 카드
- 채팅 영역
- 텍스트 입력
- 음성 파일 업로드
- 기저귀 사진 업로드
- 빠른 기록 버튼
- 지역명 입력이 필요한 병원 검색 결과

빠른 버튼:

`[🍼 수유]` `[🌙 수면]` `[💩 배변]` `[📏 성장]`

## 6. 기록 승인 UI

### 음성 예시

1. 음성 업로드
2. STT 결과 표시
3. Agent가 추출한 기록 내용 표시
4. `[기록 완료]` `[수정하기]` `[취소]`
5. 승인한 경우에만 저장 결과 표시

> 오후 2시 30분, 분유 100ml로 기록할까요?
> 

버튼을 한 번 누른 뒤에는 중복 클릭을 막고 처리 상태를 보여줍니다. 승인 요청이 만료되면 다시 확인하도록 안내합니다.

## 7. 기저귀 사진

- 업로드 전 지원 형식·최대 크기 안내
- 분석 중 Spinner
- 관찰 결과와 안전 문구
- `[배변 기록에 저장]` `[취소]` `[지역명으로 소아과 찾기]`
- 저장 버튼을 눌러도 기록 내용을 한 번 더 확인
- 원본 사진은 영구 저장하지 않는다고 안내

## 8. 육아 지식 답변

답변 카드에 다음을 표시합니다.

- 아기 월령과 수유 방식 반영 여부
- 알레르기 확인 결과
- 검색된 근거 기반 답변
- 자료 제목·발행기관·확인일
- 신뢰도 또는 근거 부족 안내
- 의료 진단이 아니라는 주의 문구

## 9. 의료기관 검색

“주변 병원”이라고 입력해도 현재 위치를 자동 사용하지 않습니다.

> 어느 지역을 기준으로 검색할까요?
> 

지역명 입력 예: `서울특별시 동작구`

검색 결과 카드:

- 병원명
- 주소
- 전화번호
- 기관 구분
- 확인 시각
- 방문 전 전화 확인 안내

## 10. 육아 관리

### 생활 기록

- 오늘·7일·30일 필터
- 수유·수면·배변·성장 종류 필터
- 기록 목록과 패턴 요약
- 수정·삭제 버튼
- 수정 내용 확인 Modal
- 삭제 최종 확인 Modal

### 성장

- 키·몸무게·머리둘레 그래프
- 월령·성별 참고 기준
- 백분위는 진단이 아닌 참고값이라는 설명

### 예방접종

- 가짜 완료 내역
- 다음 접종명·차수·예정일
- 실제 의료 기록이 아니라 테스트 데이터라는 표시

## 11. 내 정보

- 보호자 테스트 정보
- 아기 이름·생년월일·성별
- 키·몸무게
- 수유 방식
- 알레르기
- 수유 알림 간격

아기 정보와 알레르기를 수정할 때 확인 버튼을 보여주고 FastAPI를 통해 PostgreSQL에 저장합니다.

## 12. 화면 상태

- Loading: Spinner와 버튼 잠금
- Empty: 기록이 부족하다는 안내와 빠른 기록 버튼
- Validation error: 잘못된 값 바로 표시
- API error: 재시도 안내
- Approval pending: 확인 카드 표시
- Approval expired: 다시 요청 안내
- MCP/RAG unavailable: 추측하지 않고 일시적 오류 표시

## 13. session_state 예시

```python
st.session_state["user_id"]
st.session_state["baby_id"]
st.session_state["session_id"]
st.session_state["selected_menu"]
st.session_state["pending_tool_call_id"]
```

`session_state`는 화면 상태이며 영구 DB가 아닙니다. 새로고침이나 서버 재시작에도 필요한 정보는 FastAPI·PostgreSQL 또는 Redis에서 다시 조회합니다.

## 14. 시연 핵심 시나리오

1. 테스트 사용자 로그인
2. 아기 정보와 알레르기 확인
3. 수유 알림에서 수유 기록 승인
4. 음성으로 “분유 100ml 먹었어” 입력 후 승인
5. 생활 기록과 패턴 확인
6. 월령별 수유 질문과 출처 확인

8. 지역명으로 소아과 검색
9. 가짜 예방접종 일정 확인
